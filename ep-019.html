EP 19.从网页到智能体：AI 编程如何重写软件经济学？——斯坦福《AI 超周期经济学》Coding AI 精读

原文：Applications, Coding AI（斯坦福 MS&E 435《Economics of the AI Supercycle》）。定位：一个从十一岁远程接单、做到全球开发者云平台的创始人，看 AI 编程把软件世界的重心搬到了哪里——从网页到智能体，从席位到 token。

带走三句判断：写代码并不让你特别，把代码部署出去、放到客户面前才特别；云的本质正在从卖服务器转向卖会办事的 agent；token 成了新的硬通货，席位定价要让路。下次再听到「AI 要取代程序员」，可以先问：门槛归零之后，送到客户面前的能力会不会反而更稀缺？

1. 课程导读 · 公司近况

本期精讲 Stanford MS&E 435（Spring 2026）《Economics of the AI Supercycle》应用专题 Coding AI。嘉宾 Guillermo Rauch（Vercel 创始人兼 CEO、Next.js 作者）。检索日 2026-09-19。

产品与组织

  • 2026-09-17 Vercel 官方：AI Gateway Production Index（统计至 2026-08）称开源权重模型首次占网关 token 量多数（八月约 56%）；单 token 均价连续第三个月下降。一手：Vercel Blog · AI Gateway Production Index
  • 2026-09-18 Vercel 官方：与 Hacktron 复现并披露 libheif 远程代码执行，漏洞在上游解码库而非 Next.js 本体；平台侧已做图片优化缓解，并推动 Next.js 安全发布关闭 AVIF 优化。一手：Vercel Blog · libheif
  • 课上主线对照：AI 网关被讲成 token 世界的 CDN；沙盒被讲成 agent 的虚拟服务器。近期官方产品叙事仍落在 Gateway 与 Sandbox 这条「智能体基础设施」上。

3. 主要话题时间线

时间话题
0:06开场：发声；和希望低阻力输入、高质感表达的朋友打磨输入输出系统。今天读斯坦福 Coding AI / Guillermo Rauch。
2:22英文金句：他靠读软件手册自学英语，十一岁就做远程 JavaScript 外包。

3:38英文金句：开源对他毫不费力；难的是在开源之上做出一门 contrarian 的生意。
3:48讲解 open source、on top of、contrarian。转入部署网站的顿悟。
4:51英文金句：用当时最先进的技术部署一个破网站，不该那么难。
5:03讲解 epiphany、freaking、deploy。转入能造软件的人扩了数量级。
6:11英文金句：AI 与编码智能体让能造软件的人扩大十倍、二十倍乃至一百倍。
6:26讲解 expansion 与 TAM。转入花生酱配果冻。
7:25英文金句：写代码不特别；把代码放到客户面前才特别。Vercel 成了编码智能体的 PB&J。
7:38讲解 peanut butter and jelly 与「到达才值钱」。转入云该叫 AAS。
8:42英文金句：若亚马逊今天才创立 AWS，它八成会叫 Amazon Agent Services。
8:54讲解 essence、primitives。转入 agent 不再随叫随到。
9:59英文金句：响应从几秒拉到几分钟、几小时，有的 agent 会干上一整天。
10:11讲解 long-thinking streams；电商每慢一百毫秒转化率掉约百分之一。转入 token 硬通货。
11:15英文金句：token 成了新的热门商品；席位定价要让路给按智能消耗计价。
11:29讲解 commodity、seat-based vs token-based。转入 AI 网关。
12:30英文金句：AI 网关像 token 版 CDN，要故障转移、加固、加速与缓存。
12:42讲解 category-defining、fail over、semantic cache。转入给 agent 一台电脑。
13:48英文金句：给 agent 一台电脑它更强；训练后阶段模型被放进带沙盒的容器里练手。
13:57讲解 sandbox 像 agent 的 EC2。转入 agent 也会被钓鱼。
15:07英文金句：个人电脑带来病毒与钓鱼；agent 也可能外泄数据。
15:15讲解 phishing、exfiltrate。转入积木经济。
16:21英文金句：HashiCorp 创始人说这是积木经济，积木要符合智能体人体工学。
16:31讲解 block economy、agentic ergonomics、composability。转入 vibe coding。
17:36英文金句：他们 CEO 用 V0 现场写码，换掉了停车场管理软件。
17:44讲解 vibe coding、throwaway、软件几乎免费。转入真正的变化在受众。
18:53英文金句：大变化是受众；终将走向 agent 对 agent 沟通。
19:01讲解 audience、DM、evals。转入价值汇聚到前门。
20:15英文金句：价值会在哪一层积聚？执念是成为地球上每个新兴想法的前门。
20:24讲解 accrue、front door、guardrails、KYC 与放开速率限制。转入主题升华。
21:48主题升华：从个人稀缺、到部署才值钱、再到 front door 平台。
23:04英文金句：Writing code doesn't make you special. Deploying code and putting it in front of a customer does.
23:11讲解收尾：写代码门槛归零后，送到客户面前的能力更稀缺；订阅：把表达练成肌肉记忆。
