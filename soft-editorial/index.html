投资财经播客细分 · 一手浓度

按一手信息浓度与来源类型，大致是：产品 / 平台构建者 ≈ GP / 出资人视角 ≥ 财报 / IR · 公司史分化 · 卖方较低。

i. 产品 / 平台构建者 高
Lenny's · Hard Fork · No Priors · BG2 · DeepMind The Podcast
覆盖 AI · 产品 · 平台与监管 一手价值 当事人原话：产品 / 增长 / 模型路线；时效与操作一手最高
ii. GP / 出资人视角 高
a16z · 20VC · Invest Like the Best · Code Call
覆盖 VC / 成长 · AI · 软件 · 部分机构与代码向访谈 一手价值 GP / 创始人框架与募投管退判断；Code Call 补机构侧一手

吸收一手判断的卡点

i.
没听说过价值
不知道播客里藏着可入 thesis 的一手判断；没进过这个信息源地图。
ii.
语言卡点
英文原声 + 金融黑话；听懂成本高，中英工作流几乎缺位。
iii.
太耗时 / 要筛选记录
时长长、集数多；筛选、收听、记笔记本身就是一门工。
iv.
更爱文字不爱声音
效率偏好文字交互；声音形态本身就拦了一批重度投研用户。

空白为何存在 · 更早没有

一句话

播客内容早就在；卡点是「音频不可搜、不可引、不可规模监控」。2022–2023 廉价准转录 + ChatGPT/RAG 同时成熟，才在 2024–2026 挤出产品。

更早没有 · 约 2018–2022

i.
ASR 贵且不准
人工约 $1.5–2/分钟，一小时近 百美元；百万集回填不成立。
ii.
没有长稿语义检索
顶多搜标题 / shownotes；TREC 2020 就写「按说了什么搜」还不成熟。
iii.
Google / LLM 不听 MP3
多数集只有 RSS 元数据，网页答引擎几乎看不见。
iv.
产品停在人工 clip / 学习浓缩
不能当 IC 证据层，也做不了全库 alerts。
v.
分析师习惯不「搜播客」
默认 filing、研报、专家 call。

这两年解锁

解锁条件叠齐 · 约 2022 起 → 产品挤出 2024–2026

i.
Whisper（2022–23）
API 约 $0.006/分钟，约比人工低 300×；全库回填才经济。
ii.
ChatGPT + embeddings / RAG
从「存稿」变成「问 → 总结 → 切片」；Podscan 创始人直言：早三四年单人做不了。
iii.
供给到位
商业 / CEO 长访谈密度高，全球听众约 5 亿 量级，年更集数大幅上涨。
iv.
买方压力
专家 call / AlphaSense 仍贵；另类数据预算上行；OPC / 小团队要可支付一手。
v.
LLM 做研究把缺口照亮
一试就发现播客判断覆盖差 → 产品机会。
vi.
入局时间本身是证据
Matterfact、Podscan 约 2024；Seraphina、Podket 约 2026。
