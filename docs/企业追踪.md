# 企业追踪

工作台 `/workbench/` 里的「企业追踪」是一张投资论点底稿。判断默认是「观察中」，论点标着 AI草稿，给 Joyce 改。页面顶部有一句「非投资建议」。

## 公司从哪来

`workbench/build.py` 读 `workbench/companies.json`，再拿 `episodes.json` 和 `shownotes/` 对名字。

- 标题、访谈嘉宾，或导读前段对上了，算主线。
- 只在正文里出现，算提及。
- `queue/` 里没有待写选题。彩排样本还是 DoorDash，不另开一家。
- Notion、Higgsfield 不在已发布节目里，不加。EP 08 同时挂了吴恩达的好几家机构，不猜一个雇主。

改完底稿后刷新页面里的嵌入数据：

```bash
python3 workbench/build.py
```

这只写 `workbench/data.json` 和 `workbench/index.html`，不动 `feed.xml`、`episodes.json` 和节目页。

## 数字

每一条带数字的事实要有：数值、单位、期间、日期、来源标题、来源 URL、类型。类型只有这五种：官方披露、财报、媒体报道、分析师预测、播客中嘉宾原话。

没有公开数字就写「未公开」，不要补一个看起来像的数。预测只保留来源自己写出来的指引，并标成预测。超过 90 天的日期在页面上标红。

本机可以改判断、改一句话、新增公司。这些进浏览器的 localStorage，可以用导出 / 导入 JSON 带走。导出 Markdown 是为了贴进飞书。仓库里的底稿仍是 `companies.json`。

## 过期名单

不访问网络，也不读密钥：

```bash
python3 scripts/companies_refresh.py
```

它列出过期字段，然后退出 0。历史数字过期是正常的，不要为了这个把 CI 打红。只有你想把过期当成失败时才加 `--strict`。
